# Decisions

1. The project lives at the repository root, not in a nested `netflix-recommender/` directory, because this repository was already the project.
2. Schema checks are hand-rolled in `src/data/schema.py` rather than pandera, so a missing column raises `SchemaError` with the columns that were present, and the image does not carry another dependency.
3. `cast` and `description` are optional. This extract does not have them. The loader fills them with an empty string and logs a warning. They are never filled with `Unknown`.
4. Missing director, cast, and country values include the sentinel `Not Given`, plus `n/a`, `na`, `none`, `null`, `nan`, and `unknown`. The film titled Unknown is a title, so that token is only stripped from person and place fields.
5. Excel coerced a handful of titles into dates, times, and numbers. `src/data/repairs.py` restores them from the public Netflix titles list, and only when the cell still looks coerced. Mojibake (UTF-8 read as Latin-1) is reversed the same way. Both repairs run in `scripts/prepare_raw.py` and again in `clean.py`, so a re-run is safe.
6. `date_added` in the spreadsheet was a mix of datetimes and strings. The CSV stores ISO dates. The parser also accepts the month-name form from the brief.
7. Country weight is 0 in the shipped model. This extract never has a multi-country cell, and 421 rows are labelled Pakistan, including titles whose genres are Korean or otherwise not Pakistani. The ablation still fits country weight 1.
8. `genre_words` (weight 1) is extra text beside the collapsed genre token (weight 3). A cold-start query such as "crime drama" can then match. The collapsed token is still the stronger signal. TF-IDF down-weights hub words such as "movies"; a count vectoriser does not.
9. Serving uses on-demand sparse cosine: the stored matrix is L2-normalised CSR, and a request is one sparse dot product. A brute-force `NearestNeighbors` index is saved as `nn_index.joblib` so the artifact exists, and request time does not use it, because it would keep a second copy of the matrix. The full dense pair matrix is not built. A precomputed top-50 table was not added; the matvec is already fast enough.
10. `candidate_pool` (400) caps how many raw neighbours are sorted before the franchise filter. N is at most 50, so the filter still has room to drop sequels without an argsort of the whole catalogue on every evaluation row.
11. Duplicate titles are kept in the catalogue (dedup is on `show_id` only). An exact normalised title that hits more than one row returns 404 with `Title [Type, Year]` suggestions unless `content_type` selects one. The query row and other rows with the same normalised title are never returned as recommendations.
12. Near-title matching uses a token score on RapidFuzz-normalised text, not raw `WRatio`. Every query token must line up, in order, with a title token: exact, a typo (`ratio` at least 80, so `shadws` matches `shadows`), or a shortened prefix whose remainder is `s`, `es`, `ing`, or `ed` (`break` matches `breaking`, not `breakfast`). Full coverage scores 100 minus 6 points per extra title token, so `break bad` resolves to Breaking Bad (not Break, and not Break Ke Baad) with a gap wide enough to accept. A score of at least 90 with a gap of 5 still resolves silently. Otherwise the API returns the top 5 suggestions. Typeahead uses the same score when the typed text is not a substring.
13. Genre precision is a sanity check, not accuracy. The genre field is both the feature and the label, so the number is biased upward. The report says so.
14. Qualitative verdicts are written by hand in `reports/qualitative_verdicts.json` after reading the lists. `scripts/evaluate.py` only inserts them.
15. The Docker build context ignores `data/raw/*` but re-includes `netflix_titles.csv`, because the image trains during build and the runtime layer does not need the CSV.
16. Python 3.11 is the project interpreter. On this machine it is the uv-installed CPython 3.11.15 in `.venv`, because `py -3.11` was not on PATH.
17. There is no live deployment and no CI badge. Nothing was pushed from this working tree, and a badge for a workflow that has not run would be red or empty.
18. The shipped model stays TF-IDF with genre weight 3 even though genre weight 6 and the count vectoriser score slightly higher on genre precision. That metric is circular. The count vectoriser ties whole genre buckets at 1.0, which is the failure the qualitative audit shows. TF-IDF plus the director token is what separates The Irishman from a generic drama.
19. `metadata.json` records the source CSV as a repo-relative path (`data/raw/netflix_titles.csv`). The SHA-256 is the check that the file did not change.
20. `.git` is excluded from the Docker build, so the model trained inside the image records `git_commit` as `unknown`. The host training run records the real SHA. The image is 944 MB, under the 1.5 GB cap. Streamlit is in the same image as the API, which is why it is not under 800 MB.
21. Reasons say "genre overlap only" when no person is shared, and "saturated" when cosine is at least 0.99. A score of 1.0 on a shared genre string was being read as a confident match. There is still no accuracy number, because there are no watch labels.
22. Free-text queries expand `drama` to `dramas` and `comedy` to `comedies`, and join a known person name into the collapsed token the vectoriser stored. `romance` is rewritten to `romantic`, because that is the catalogue genre word. A description that is actually a catalogue title is sent through title search. Mood words that are not in the catalogue are refused.
23. Poster art is not a Netflix API. Netflix does not publish a free poster endpoint. The UI asks TVMaze (TV stills, no key) and the English Wikipedia REST summary (movie posters, no key). If `TMDB_API_KEY` is set, TMDB is tried first. Misses render a title card. Image files are not stored in the repo.
24. `rating` is an optional exact filter on both recommend routes. This extract has no plot text, so a card shows the catalogue description when one exists and otherwise a short Wikipedia or TVMaze summary. The model reason stays behind See more.
